# 参数化预览渲染设计

## 目标

将基础绑定项目中的参数值映射为可观察的静态 PNG 变化，验证清单、参数、图层和预览输出之间的数据链路。

## 范围

预览器只使用 Pillow 对同画布 PNG 做轻量 Alpha 变换：虹膜平移、眼睛纵向缩放、上眼皮下移、嘴部纵向缩放、身体呼吸缩放和头部小角度旋转。它不实现网格、物理、透视或摄像头驱动。

## 约束

- 参数必须来自项目模板，未知参数和越界值直接报错；
- 输入存在校验错误时不生成输出；
- 图层按 `draw_order` 稳定合成；
- 变换按角色语义应用，不能读取具体角色名称；
- 生成图仅用于验证链路，粗糙蒙版造成的接缝由后续人工修层处理。
